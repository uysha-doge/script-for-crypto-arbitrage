The script works as follows: it searches for the lowest price for a coin to buy and the highest price to sell. In the JSON file, you need to specify the coin(s); you can list multiple coins. You also need to choose the exchange filter as true or false. If ex_filter is "false", the script searches for pairs on all exchanges. If ex_filter is "true", it only searches for pairs on the exchanges listed in the JSON file. In the JSON file, you can specify the exchanges where you want to search for pairs. In investment, you need to specify the amount you plan to use, and in currency, you need to specify the currency in which the buy and sell prices will be calculated.
